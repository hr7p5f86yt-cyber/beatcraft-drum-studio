連符・連桁
譜面をタップ/クリックして音符を置きます。同じ楽器を同じ位置にもう一度置くと消えます。「消去」モードでは音符の近くをタップすると、その音符だけ消えます。休符は自動で入ります。小節の番号をタップすると、拍子・リハーサル記号(A,B…)・小節の挿入や削除ができます。iPadでは画面下のパッドをタップするとカーソル位置に入力され、次へ進みます(「範囲選択」で複数の音符をまとめて選べます)。iPadの消音スイッチがオンだと音が出ません。キーボードがあれば、矢印キー(←→で位置・↑↓でパーツ)と C/H/O/R/T/S/L/K キーで入力できます(「⌨ キー操作一覧」を参照)。間違えたら「↩ 戻す」(Ctrl+Z)で何度でも一つ前に戻れます。

小節の設定

画像・PDFから楽譜を取り込む

ドラム譜(5線・ハイハットは×印)の画像、スキャン、写真、PDFを選びます。アプリ内の簡易読み取りなので、音符の長さは位置から推定します。取り込み後に手直しが必要です。
(画像をここへドロップ/貼り付けもできます)

録音した音(サンプル)を使う

ハイハットやシンバルなど、録音されたドラムの音ファイル(wav / flac / mp3 / m4a / ogg)を選ぶと、合成音の代わりに使います。再配布してよいライセンス(CC0など)の音源を使ってください。同じパーツに複数のファイルを選ぶと、音の大きい順に「弱い→強い」として、演奏の強さに合わせて使い分けます。
ファイル名に crash / ride / open hat / hihat / snare / kick / tom などが入っていると自動で判定します。判定できないものは、下のパーツごとの「選ぶ」から追加してください。

キーボード操作

楽譜上に青い縦線(カーソル)が出ます。カーソルは「次に音符を置く位置」で、クリックした位置/最後に入力した位置に出ます。
← →カーソルを、いま選んでいる音符の長さぶん前後へ動かす(小節をまたぐ)
Shift+←→範囲を選ぶ(アクセント・連符変換・クレッシェンドなどの対象になる)。Escで解除
↑ ↓パーツ(楽器)を切り替える
PageUp PageDown Home End前/次の小節、最初、最後の小節へ
C H O R T S L Kクラッシュ / ハイハット / オープンHH / ライド / ハイタム / スネア / ロータム / キック をカーソル位置に入力(Shiftを押すと、カーソルを進める/進めないが逆になる)
Enter選んでいるパーツを入力(同じ所にもう一度で消える)
Backspace Deleteカーソル位置の音符を消す(Backspaceは一つ戻る)
1〜6音符の長さ: 全 / 2分 / 4分 / 8分 / 16分 / 32分

< >クレッシェンド / デクレッシェンド(範囲選択があればその範囲、なければ小節の終わりまで)
