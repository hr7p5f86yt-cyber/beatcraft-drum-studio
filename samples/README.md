# samples/

録音したドラムの音ファイルを置く場所です(今は空)。アプリの「🥁 録音した音を使う」から読み込めます。

- **再配布してよいライセンス(CC0 など)の音源だけ**を置いてください。ライセンスが分からない音源・有料キットの音は置かないでください。
- 音源ごとの出典とライセンスを、このフォルダに `SOURCES.md` として書いておくと安心です。

## 出典・クレジット(使った音源を書く場所)

音源を配布・公開する場合は、ここに出典と作者・ライセンスを書きます。例:

- Salamander Drumkit by Alexander Holm, licensed under CC BY-SA 3.0 (https://creativecommons.org/licenses/by-sa/3.0/)

このリポジトリ自体には音源ファイルを入れていません。
